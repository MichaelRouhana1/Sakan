# Studently — Logo guidelines

Direction: **Threshold**. An S whose lower counter is a flat-floored room.

## Versions

| Version | Use | File |
|---|---|---|
| Horizontal, ink | Nav, documents, the default lockup | `studently-horizontal.svg` |
| Horizontal, ocean symbol | When the icon should carry the brand colour and the name stays ink | `studently-horizontal-accent.svg` |
| Stacked | Square spaces, posters, avatars with the name | `studently-stacked.svg` |
| Symbol | App icon, favicon, avatar | `studently-symbol.svg` |
| Wordmark | Where the symbol is already on screen | `studently-wordmark.svg` |
| White | Ink or ocean backgrounds | `*-white.svg` |
| App icon tile | Home screen | `export/studently-symbol-app-icon.svg` |
| Favicon set | Browser | `export/favicon.ico`, `export/head-snippet.html` |

Screen files are SVG and PNG in `kit/` and `kit/export/`. Use RGB on screen. For print, use the CMYK values below or a spot colour matched on press. There is no print PDF in this set.

## Clear space

Keep a clear margin on every side at least as wide as the **vertical stem of the S**. The margin scales with the logo.

## Minimum size

| Version | Screen | Print |
|---|---|---|
| Symbol | 16 px | 6 mm |
| Horizontal | 128 px wide | 32 mm wide |
| Stacked | 80 px wide | 20 mm wide |

The room in the lower half of the S is still visible at 16 px. Below that, use the symbol only, not the word.

## Colour

| Name | HEX | RGB | CMYK | Pantone (approximate) |
|---|---|---|---|---|
| Ink | `#121826` | 18, 24, 38 | 53, 37, 0, 85 | 532 C — proof before print |
| Ocean | `#2F6FED` | 47, 111, 237 | 80, 53, 0, 7 | 2727 C — proof before print |
| White | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 | — |

Ocean on white and white on ocean are both about **4.5 : 1**. Ink on white is about **17.7 : 1**.

Approved pairs:

- Ink on white
- Ocean symbol with an ink word on white
- White on ocean
- White on ink
- Black on white, for one-colour print (`export/*-black.svg`)

Ocean is the colour already used in the Studently interface. Blue is common for education products; it is kept here so the logo and the app match, not as a new colour picked from the category.

## Typography

The word **studently** in the logo is a custom drawing, not a font. Do not retype it.

The app interface already uses **DM Sans** (SIL Open Font License) for UI text. That is the text face beside the logo, not a substitute for it.

## Do not

- Stretch, rotate, outline, shadow, or gradient the mark
- Recolour it outside ink, ocean, white, and black
- Rearrange the lockup or change the gap between the S and the word
- Set the name in DM Sans and call it the logo
- Place the mark on a busy photo without the white or ink version on a quiet area
